儲存設定

快速設定
  1. 在 GitHub 建立私人（Private）儲存庫，例如 my-drive，並建立 main 分支（勾選 Add README 即可）。
  2. Settings → Developer settings → Fine-grained tokens → 只授權該儲存庫，權限 Contents: Read and write。
  3. 填入上方欄位後按「測試連線」。每次儲存都是一次 Git commit，可在「歷史」還原舊版。

⚠ 若儲存庫是公開的，所有文件都會被公開。Token 只存在本機瀏覽器，請勿在公用電腦記住它。
